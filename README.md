## PROJECT ONE

### CacheScope

CacheScope is an interactive CPU cache simulation and visualization platform designed to help students, educators, and systems programmers better understand cache architecture, memory mapping, and runtime cache behavior. The project combines computer architecture concepts with formal software engineering practices, including requirements-driven development, UML modeling, GRASP-based design, and modular simulation architecture.

**Technologies:**
**Frontend**
• TypeScript
• Vite
• Web Components
• HTML/CSS
• SVG/Canvas Visualization.

**Backend**
• C++
• CMake
• Custom HashSet implementation
• REST API architecture
• GitHub Actions
• Markdown-based architecture documentation.

## PROJECT TWO

### MealEngine

MealEngine is an iOS app with optimized meal recommendations that help the user meet their dietary goals before (not after) meals are consumed. The functionalities include user settings, food search, smart recommendations, meal logging, and nutrition tracking. My contribution to this project include the conceptual idea, the minimum viable product comprising the optimization algorithm, local persistence, REST API integration, SwiftUI, disk and memory caching, input validation, MVVM architecture, and documentation.

**Technologies:** 
• Swift
• SwiftUI
• Local Persistence (UserDefaults / file storage)
• REST API integration
• Knapsack Optimization.
